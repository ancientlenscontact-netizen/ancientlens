# Security reporting

Report suspected vulnerabilities privately to ancientlens.contact@gmail.com. Include affected URL/version, reproduction steps using your own test account, and expected versus actual behavior. Do not send passwords, recovery codes, private databases or other users’ data. Stop testing if private data becomes accessible.

The solo maintainer reviews reports; there is no guaranteed response SLA or bounty program. Only the current public pilot release is maintained. Do not disclose an unresolved vulnerability through a public issue. Account recovery uses a saved recovery code; operator identity overrides are not offered.

Self-hosters must keep secrets outside their checkout, restrict research tools to local use, configure HTTPS/origin validation, and test restoration and removal-ledger replay. Backups contain private material and must never be published with the dataset.
