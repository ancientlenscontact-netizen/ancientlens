# Contributing

AncientLens welcomes enthusiasts and specialists. Academic credentials are not required. Public pilot: https://ancientlens.org/.

## Translations

Open an artifact, choose **Contribute / community translations**, and select the exact inscription. Sign in, write your original translation, cite sources, credit authors, preserve uncertainty and disclose AI assistance. Accept CC BY-SA4.0 for each revision. Do not copy copyrighted translations merely because they are online. See the [contributor terms](https://ancientlens.org/contributor-terms-2026-09-16.1.html).

Submissions start pending moderation and scholarly unreviewed. Moderation controls visibility; it does not certify a reading or ownership declaration. Existing museum wording remains separate. Owners can revise or withdraw contributions; account closure and erasure review have retention limits described in the [privacy notice](https://ancientlens.org/privacy.html).

## Corrections and artifact suggestions

Send the artifact link, museum/source URL, proposed correction and rights evidence to ancientlens.contact@gmail.com. Do not send private account data or unsupported reconstructed readings. Additional acquisition requires provenance and compatible reuse rights. Report visible community revisions using their report control.

## Code

Project-owned code contributions use MIT. Start from the source release and follow README setup/tests. Describe the problem, changed behavior and validation. Preserve source wording, stable IDs, scholarly uncertainty and privacy boundaries. Never commit credentials, SQLite files, private notes, backups or research photographs. Source changes should be proposed as a patch or pull request once a repository host is linked from the release page.

For vulnerabilities follow SECURITY.md rather than a public issue.
